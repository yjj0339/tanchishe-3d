# 贪吃蛇大作战 3D

**在线玩：<https://yjj0339.github.io/tanchishe-3d/>**

二十蛇混战的 3D 贪吃蛇大作战 3.0「巨蛇修罗场」。Blender 卡通蛇头 + Three.js 渲染，超浅明亮画风，蛇可长到 300 节依旧流畅，手机电脑都能玩。

## 玩法

- **吃光点**变长变粗；金蛋 = 12 分大礼包；快速连吃触发**连击加成**（最高 ×2）
- **撞别人身体即死**，死后化为满地光点；引诱对手撞你的身体完成击杀
- 按住**加速**冲刺（掉分数）；击杀大蛇有**赏金**，4 秒内连杀还有双杀/多杀播报
- 出生带 2.5 秒闪烁护盾；撞世界边界即死；玩家死亡有慢镜头

## 随机事件（每 30 秒左右降临一次）

| 事件 | 内容 |
|---|---|
| 光点雨 | 全场疯狂撒粮 6 秒，抢到手软 |
| 双倍狂欢 | 10 秒内全场吃食得分 ×2 |
| 蛇王降临 | 金色巨蛇王 Boss 全场追杀，击杀者 +100 分以上赏金与满地黄金 |

## 场上系统

- **5 种道具**：磁铁吸食 / 护盾反杀 / 免费疾速 / 双倍积分 / 幽灵穿身（每 7–12 秒刷新）
- **双色传送门**：黄蓝两门瞬时互换位置，穿门有 3 秒冷却
- **金冠**：实时分数榜首之蛇头顶旋转金冠
- **18 项成就**：屠蛇者、传送大师、王者风范、蛇王登基、集齐五宝……弹窗+音效
- 蛇王榜实时排名、击杀播报、圆形小地图（含传送门与蛇王金点）、历史最佳 5 局

## 个性化与对手

- 24 种皮肤颜色 × 4 种花纹（纯色 / 环纹 / 渐变 / 彩虹）
- 19 条 AI 四种性格：猎手包抄截杀、贪吃蛇闷头吃、胆小蛇远远就跑——都会捡道具、抢传送门

## 技术

- Blender 5.2 建模卡通蛇头（大眼+信子）导出 GLB，按蛇色染色
- Three.js r170：蛇身 InstancedMesh + 单遍轨迹采样（O(路径长)、对任意帧率免疫）
- 场地半径 220、最多 1700 颗光点、蛇长上限 300 节，实测 215 节巨蛇逻辑每帧 0.31ms
- WebAudio 合成全部音效与四和弦背景音乐，零外部资源
