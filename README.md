# 贪吃蛇大作战 3D

**在线玩：<https://yjj0339.github.io/tanchishe-3d/>**

十六蛇混战的 3D 贪吃蛇大作战。Blender 卡通蛇头模型 + Three.js 渲染，明亮浅色画风，手机电脑都能玩。

## 玩法

- **吃光点**变长变粗，大光点（大蛇死亡掉落）涨分更快
- **撞别人身体即死**，死后化为满地光点；让对手撞上你的身体来击杀它
- 按住**加速**冲刺（掉分数），用于抢食、逃生或绕前截杀
- 撞世界边界、撞自己不死（本作无自撞），出生有 2.5 秒闪烁护盾
- 右上蛇王榜实时排名，左下小地图看全局

## 操作

| 平台 | 转向 | 加速 |
|---|---|---|
| 电脑 | 移动鼠标 | 按住左键 / 空格 |
| 手机 | 手指拖屏幕 | 右下「加速」按钮 |

## 技术

- Blender 5.2 建模卡通蛇头（大眼+信子）导出 GLB，游戏内按蛇色染色
- Three.js r170，蛇身 InstancedMesh + 路径采样，全部蛇/食物/阴影实例化渲染
- AI：探路避障（三向射线探测）、抢食、逃避大蛇、包抄猎物、随机加速
- 击杀音效 WebAudio 合成，零外部资源依赖（three 与模型全部本地化）

本地预览：`node tools/server.js` 后开 `http://localhost:8935/`
