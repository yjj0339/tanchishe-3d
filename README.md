# 贪吃蛇大作战 3D

**在线玩：<https://yjj0339.github.io/tanchishe-3d/>**

二十蛇混战的 3D 贪吃蛇大作战 4.0「风暴纪元」。Blender 卡通蛇头 + Three.js 渲染，超浅明亮画风，蛇可长到 300 节依旧流畅，手机电脑都能玩。

## 风暴缩圈（4.0 新增 · 大逃杀终局）

90 秒风暴预警 → 135 秒开始缩圈：紫色风暴墙步步逼近，**圈外每秒掉 18 分，归零即被风暴吞噬**；安全区内的光点与重生点全部向圈内收拢，AI 也会拼命往里逃——最终决战永远发生在风暴眼。

## 本局任务

每局随机抽 3 个任务（吃光点 / 完成击杀 / 穿传送门 / 戴金冠 / 拾道具 / 吃金蛋 / 登前三……），右上角面板实时显示进度条；单个完成 +30 分，**三个全部完成 +100 分**并解锁「任务大师」成就。300 分以上的大蛇死亡时全场播报「巨蛇陨落！」。

## 场上系统

- **7 种道具**：磁铁吸食 / 护盾反杀 / 免费疾速 / 双倍积分 / 幽灵穿身 / **冰冻周围（4.0：冻慢身边所有对手）** / **缩小保命（4.0：长度瞬间减半逃生）**
- **双色传送门**：黄蓝两门瞬时互换位置，穿门有 3 秒冷却与 1.2 秒保护
- **金冠**：实时分数榜首之蛇头顶旋转金冠
- **20 项成就**：风暴行者、屠蛇者、任务大师、传送大师、王者风范……弹窗+音效
- 蛇王榜实时排名、击杀播报、圆形小地图（含风暴圈/传送门/蛇王金点）、历史最佳 5 局
- 细节：同分对撞公平随机判负、吃食音调随连击爬升、死亡慢镜头

## 个性化与对手

- 24 种皮肤颜色 × 4 种花纹（纯色 / 环纹 / 渐变 / 彩虹）
- 19 条 AI 四种性格：猎手包抄截杀、贪吃蛇闷头吃、胆小蛇远远就跑——都会捡道具、抢传送门

## 技术

- Blender 5.2 建模卡通蛇头（大眼+信子）导出 GLB，按蛇色染色
- Three.js r170：蛇身 InstancedMesh + 单遍轨迹采样（O(路径长)、对任意帧率免疫）
- 场地半径 220、最多 1700 颗光点、蛇长上限 300 节；**食物空间哈希网格**（计数排序分桶，碰撞检查从每帧 3.4 万次降到几千）
- WebAudio 合成全部音效与四和弦背景音乐，零外部资源

本地预览：`node tools/server.js` 后开 `http://localhost:8935/`
