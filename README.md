# 贪吃蛇大作战 3D

**在线玩：<https://yjj0339.github.io/tanchishe-3d/>**

二十蛇混战的 3D 贪吃蛇大作战 5.2「雾都山城」——世界以重庆为蓝本重设计。Blender 卡通蛇头 + Three.js 渲染，超浅明亮画风，手机完整适配。

## 雾都山城（5.2 重庆主题）

- **朝天门两江交汇**：中央大湖是一半金黄长江、一半碧绿嘉陵江的双色交汇，白色汇流线蜿蜒，入江加速 18%，江中银鱼 4 分
- **洪崖洞吊脚楼**：湖岸一排金色层叠吊脚楼+红檐
- **轻轨穿楼**：环湖高架轻轨线，一栋楼骑在线上，蓝白列车绕湖飞驰
- **长江索道**：一条缆索横贯全场，两只红色缆车来回摆渡
- **解放碑**：湖畔白色碑塔金色碑顶
- **山城群山**：竞技场外圈层叠青山

## 手机完整适配（5.2）

- 单指拖动转向、**双指同按或加速按钮**冲刺、击杀/死亡震动反馈
- 按钮右侧竖排不遮挡、安全区适配、防误触过度滚动、一键全屏
- 手机默认「均衡」画质档+低帧自动降档，竖屏自动放宽视野（FOV 72）

## 经典玩法

风暴缩圈（闪电雷鸣）、7 种道具、双色传送门、蛇王/双蛇王之战、彩虹星抢星、本局 3 任务、20 成就、24 色×4 花纹皮肤+7 款帽子、昼夜循环、六色生态区。

## 技术

- Blender 5.2 卡通蛇头 GLB；Three.js r170 实例化渲染 + 单遍轨迹采样 + 食物空间哈希网格
- 蛇长上限 300 节，实测 0.3~0.6ms/帧；WebAudio 合成音效+BGM，零外部资源

本地预览：`node tools/server.js` 后开 `http://localhost:8935/`


## 幻彩大陆（5.0 全新）

- **六色生态区**：樱花粉、薄荷绿、晴空蓝、奶油黄、薰衣草紫、蜜桃橙六色扇形拼图大地，每区专属景观——樱花林/水晶簇/蘑菇圈/岩石滩/棕榈丛，场内还有随机小花
- **昼夜循环**：白昼→黄昏→月夜→黎明 4 分钟连续演变，天空、雾、阳光、地面色调同步流转（全程保持明亮）
- **蛇身滑行波**：蛇真正扭动着游动并呼吸脉动，不再是僵硬的贴路径移动
- **彩虹星**：30 分稀有食物，全图可见的彩虹光柱指引，刷新即引发全场抢星大乱斗

## 风暴缩圈

90 秒预警 → 135 秒缩圈：紫色风暴墙步步逼近伴随闪电雷鸣，圈外每秒掉 18 分归零即被吞噬，安全区内的光点与重生点全部向圈内收拢。

## 场上系统

- **7 种道具**：磁铁吸食 / 护盾反杀 / 免费疾速 / 双倍积分 / 幽灵穿身 / 冰冻周围（冻慢+冰蓝染色）/ 缩小保命
- **双色传送门**：瞬移互换 + 3 秒冷却 + 1.2 秒保护
- **金冠**：榜首之蛇头顶旋转金冠并撒落金粉
- **本局任务**：每局随机 3 个任务实时进度条，单个 +30 全完 +100
- **20 项成就**：风暴行者、屠蛇者、任务大师、传送大师……
- 蛇王榜、击杀赏金、连击加成（音调爬升）、死亡慢镜头、历史最佳 5 局
